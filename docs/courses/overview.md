# 课程概览

Ai4Energy 项目包含以下 5 个核心课程模块：

## 课程列表

| 课程 | 描述 | 链接 |
|------|------|------|
| 📚 CS 基础 | 计算机科学基础课程 | [访问](https://huxinyang-web.github.io/ai4edocs-cs-basics/) |
| 🛠️ 开发工具 | 现代软件开发工具链 | [访问](https://huxinyang-web.github.io/ai4edocs-dev-tools/) |
| 📊 建模方法 | 数学建模与系统建模方法论 | [访问](https://huxinyang-web.github.io/ai4edocs-modeling/) |
| 📈 优化理论 | 最优化理论与方法 | [访问](https://huxinyang-web.github.io/ai4edocs-optimization/) |
| ⚡ AI 能源应用 | 人工智能在能源领域的应用 | [访问](https://huxinyang-web.github.io/ai4edocs-ai-energy/) |

## 学习建议

建议按照以下顺序学习：

1. **CS 基础** → 打好编程基础
2. **开发工具** → 掌握高效开发技能
3. **建模方法** → 学习问题建模思维
4. **优化理论** → 掌握优化求解方法
5. **AI 能源应用** → 综合应用所学知识
